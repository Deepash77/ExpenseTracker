# ExpenseTracker
# 💰 Personal Expense Tracker (Java Console App)

A simple, menu-driven **Java console application** to track your daily expenses by category. This mini-project is ideal for beginners learning Java, file handling, and object-oriented programming.

---

## 🚀 Features

- Add new expenses with category, description, and amount
- View all recorded expenses
- Delete specific expenses
- View total expenditure
- Save and load data from a file (`expenses.txt`) for persistence

---

## 🛠️ Technologies Used

- Java (JDK 8+)
- Console-based interface
- File I/O (Read/Write to `.txt`)
- OOP (Object-Oriented Programming)
